# Diagram Studio Implementation Plan

> **For agentic workers:** implement this plan task by task, in order.
> Steps use checkbox (`- [ ]`) syntax; tick them as you go.
> Each task ends with a commit on the current branch (`hiinguyen/feat-diagram-visualizing`).
> Never push, never touch `main`, never edit files outside `diagram/`, `docs/`, `.gitignore`, `.env.example` and `README.md`.
> `CLAUDE.md` is a local, untracked file: do not create, edit or commit it.

**Goal:** a Napkin-style web app (`diagram/`) that turns text, `.txt`, `.md`, `.docx`, `.pptx` or a URL into editable, themeable diagrams, generated by Claude Code locally or Hermes on a server, exported as SVG / PNG / PDF / DOCX / PPTX.

**Architecture:** the AI only returns structured JSON (`DiagramSpec`); our own isomorphic renderer (`diagram/shared/`) lays it out with 12 templates and paints it with 6 themes.
A Fastify server ingests documents, talks to the agent through one adapter interface, stores projects as JSON files and exports.
The browser UI is vanilla ES modules that import the same renderer from `/shared/`.

**Tech stack:** Node 22+ ES modules, Fastify 5, opentype.js 2, @dagrejs/dagre 3, lucide-static (icon data), Ajv 8, jszip + @xmldom/xmldom, marked, linkedom + @mozilla/readability, @resvg/resvg-js, pdfkit + svg-to-pdfkit, node:test, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-16-diagram-visualizing-design.md`.
Read it fully before Task 1; this plan implements it and copies its numbers.

## Global constraints

- **NO LIVE AI OR PAID API CALLS.** Do not run `claude`, do not call Hermes, Jev, TypeSafe, OpenAI, DeepSeek or any LLM endpoint, with or without real keys, in any task, test, script or "quick check".
  Every test and every manual check uses `DIAGRAM_AGENT=fake`.
  The only exception is Task 19 Step 5, which the human reviewer runs, not you.
  If you think you need a live call to understand an output format, read this plan again: the formats are specified here.
- Network use is limited to `npm install` and the font download in Task 1.
- Node 22 or newer, `"type": "module"` in `diagram/package.json`, no TypeScript, no bundler, no frontend framework.
- Style like `app/`: 2 spaces, single quotes, semicolons, `const` by default, small focused files (under 400 lines; split before 800).
- Immutability: functions in `shared/spec/` never mutate their inputs; they return new objects.
- No `console.log` left in committed code except the server's startup line; the server logs through Fastify's logger.
- Never use the em dash character in code, comments, docs or UI text; use a plain `-`.
- UI text is Vietnamese.
  Diagram text stays in the source language.
- Limits (from the spec): label 60 chars, detail 160 chars, title 80, subtitle 120, upload 20 MB, agent text 60,000 chars per call, URL body 5 MB, URL timeout 15 s, max 3 redirects, agent timeout 180 s, font shrink floor 75 %, undo history 100 steps, 3 candidates per section.
- Ports and defaults: host `127.0.0.1`, port `8790`, data dir `diagram/data`.
- Run `cd diagram && npm test` before every commit and keep it green.
  A test you cannot make pass is a stop-and-report, not a skip.
- Commit messages use conventional commits (`feat:`, `test:`, `fix:`, `docs:`, `chore:`), one commit per task unless a step says otherwise.
  Stage paths explicitly (`git add diagram/...`), never `git add -A`.

```js
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const DIAGRAM_ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
const AGENTS = ['claude-code', 'hermes', 'fake'];
const LOOPBACK = new Set(['127.0.0.1', '::1', 'localhost']);
const DEFAULT_PORT = 8790;
const DEFAULT_TIMEOUT_S = 180;
const DEFAULT_HERMES_MODEL = 'hermes-agent';

function nonEmpty(value) {
  const text = typeof value === 'string' ? value.trim() : '';
  return text === '' ? null : text;
}

function parsePositive(value, fallback, name) {
  if (nonEmpty(value) === null) return fallback;
  const number = Number(value);
  if (!Number.isFinite(number) || number <= 0) throw new Error(`${name} must be a positive number, got "${value}"`);
  return number;
}

export function loadConfig(env) {
  const agent = nonEmpty(env.DIAGRAM_AGENT) ?? 'claude-code';
  if (!AGENTS.includes(agent)) throw new Error(`DIAGRAM_AGENT must be one of ${AGENTS.join(', ')}, got "${agent}"`);
  const host = nonEmpty(env.DIAGRAM_HOST) ?? '127.0.0.1';
  const port = parsePositive(env.DIAGRAM_PORT, DEFAULT_PORT, 'DIAGRAM_PORT');
  if (!Number.isInteger(port) || port > 65535) throw new Error(`DIAGRAM_PORT must be a port number, got "${env.DIAGRAM_PORT}"`);
  const token = nonEmpty(env.DIAGRAM_TOKEN);
  if (!LOOPBACK.has(host) && token === null) {
    throw new Error(`DIAGRAM_TOKEN is required when DIAGRAM_HOST (${host}) is not a loopback address`);
  }
  const dataDir = path.resolve(DIAGRAM_ROOT, '..', nonEmpty(env.DIAGRAM_DATA_DIR) ?? path.join('diagram', 'data'));
  const url = nonEmpty(env.DIAGRAM_HERMES_URL) ?? nonEmpty(env.FRIDAY_AGENT_URL);
  return {
    agent,
    host,
    port,
    token,
    dataDir,
    agentTimeoutMs: parsePositive(env.DIAGRAM_AGENT_TIMEOUT_S, DEFAULT_TIMEOUT_S, 'DIAGRAM_AGENT_TIMEOUT_S') * 1000,
    claudeModel: nonEmpty(env.DIAGRAM_CLAUDE_MODEL),
    hermes: {
      url: url === null ? null : url.replace(/\/+$/, ''),
      key: nonEmpty(env.DIAGRAM_HERMES_KEY) ?? nonEmpty(env.FRIDAY_AGENT_KEY),
      model: nonEmpty(env.DIAGRAM_HERMES_MODEL) ?? nonEmpty(env.FRIDAY_AGENT_MODEL) ?? DEFAULT_HERMES_MODEL,
    },
  };
}

export { DIAGRAM_ROOT };
```

Note: `DIAGRAM_DATA_DIR` is relative to the repo root (one level above `diagram/`), absolute paths pass through `path.resolve` unchanged.

### Task 2: DiagramSpec constants, tree helpers, validation, normalization

**Files:**
- Create: `diagram/shared/spec/constants.js`, `diagram/shared/spec/tree.js`, `diagram/shared/spec/validate.js`, `diagram/shared/spec/normalize.js`
- Test: `diagram/test/spec-validate.test.js`, `diagram/test/spec-normalize.test.js`, `diagram/test/helpers/specs.js`

**Interfaces:**
- Produces:
  - `constants.js`: `SPEC_VERSION = 1`, `LIMITS = { label: 60, detail: 160, title: 80, subtitle: 120 }`, `COLOR_SLOTS = ['accent1', ..., 'accent6']`, `DENSITY_NAMES = ['compact', 'normal', 'airy']`, `DEFAULT_THEME = 'classic'`, `FALLBACK_ICON = 'circle'`, `HISTORY_LIMIT = 100`.
  - `tree.js`: `roots(spec) -> Node[]` (nodes whose `parent` is null, in array order), `childrenOf(spec, id) -> Node[]` (array order), `depthOf(spec, id) -> number` (root = 0), `descendantIds(spec, id) -> string[]`.
  - `validate.js`: `validateSpec(spec) -> string[]`, empty when valid.
  - `normalize.js`: `normalizeSpec(raw, { template, iconNames, sectionId }) -> { spec, repairs: string[] }`, where `template` is a template descriptor `{ id, minNodes, maxNodes, uses: { parent, edges, value } }` (Task 6 provides real ones; tests pass literal objects).
  - `test/helpers/specs.js`: `makeSpec(overrides)` and `makeNodes(count, overrides)` fixture builders used by every later test.

`validateSpec` rules (one message string per violation, naming the field):
- object with `version === 1`; `id`, `template`, `title` non-empty strings; `subtitle` and `lang` strings; `title` at most 80 chars, `subtitle` at most 120;
- `nodes` an array; each node: `id` non-empty string unique among nodes, `label` non-empty string at most 60, `detail` string at most 160, `icon` string, `parent` null or the id of another node, `value` null or a finite number, `emphasis` boolean, `color` null or one of `COLOR_SLOTS`;
- the parent links form no cycle;
- `edges` an array of `{ from, to, label }` where `from` and `to` are node ids and `label` a string;
- `style.theme` a string, `style.density` one of `DENSITY_NAMES`;
- `locks` an array of strings.

`normalizeSpec` steps, in this order, each repair appended to `repairs` as a short English sentence:
1. Start from `structuredClone(raw ?? {})`; set `version: 1`; `id` defaults to `'d_' + 4 random base36 chars`; `sectionId` from the option when given; `template` forced to `template.id`; `title` defaults to `''` then truncated to 80; `subtitle` to `''` and truncated to 120; `lang` to `'vi'` when missing.
2. Nodes: drop non-objects; missing or duplicate `id` gets `n1`, `n2`, ... (first unused); `label` coerced to string, trimmed, truncated to 60 chars with a trailing `…` when cut (the cut keeps 59 chars plus `…`); empty labels drop the node; `detail` to string, trimmed, truncated to 160 the same way; `icon` not in `iconNames` becomes `FALLBACK_ICON`; `parent` that is not another node's id becomes null; `value` not a finite number becomes null; `emphasis` coerced with `=== true`; `color` not in `COLOR_SLOTS` becomes null.
3. Break parent cycles: walk each node's parent chain; when a node is met twice, set the parent of the node that closed the cycle to null.
4. If `!template.uses.parent`, set every `parent` to null (repair only when one was set). If `!template.uses.value`, keep values (they are harmless) but nothing else.
5. Edges: when `template.uses.edges` keep edges whose ends exist and differ, drop duplicates (same from and to), coerce `label` to string; otherwise set `edges: []`.
6. If more nodes than `template.maxNodes`: keep the first `maxNodes` in array order (then repeat steps 2-5 effects for parents and edges pointing to removed nodes).
7. `style`: `{ theme: string or DEFAULT_THEME, density: valid or 'normal' }`; `locks`: keep strings only, de-duplicated.
8. Fewer nodes than `template.minNodes` is not repaired (nodes are never invented): `normalizeSpec` adds the repair message `too few nodes for <template id>` and returns the spec as it is.
   Every template must still render 1 node without crashing.

export const FONT_FAMILY = 'Be Vietnam Pro';
export const FONT_FILES = {
  400: 'BeVietnamPro-Regular.ttf',
  500: 'BeVietnamPro-Medium.ttf',
  600: 'BeVietnamPro-SemiBold.ttf',
  700: 'BeVietnamPro-Bold.ttf',
};

const MEASURE_CACHE_LIMIT = 20000;

export function createFontSet(opentype, buffers) {
  const fonts = {};
  for (const [weight, buffer] of Object.entries(buffers)) fonts[weight] = opentype.parse(buffer);
  if (!fonts[400]) throw new Error('the 400 weight is required');
  const pick = (weight) => fonts[weight] ?? fonts[400];
  const cache = new Map();
  return {
    measure(text, size, weight = 400) {
      const key = `${weight}|${size}|${text}`;
      let width = cache.get(key);
      if (width === undefined) {
        width = pick(weight).getAdvanceWidth(text, size, { kerning: true });
        if (cache.size > MEASURE_CACHE_LIMIT) cache.clear();
        cache.set(key, width);
      }
      return width;
    },
    pathData(text, x, baselineY, size, weight = 400) {
      return pick(weight).getPath(text, x, baselineY, size, { kerning: true }).toPathData(2);
    },
    ascent(size, weight = 400) {
      const font = pick(weight);
      return (font.ascender / font.unitsPerEm) * size;
    },
    descent(size, weight = 400) {
      const font = pick(weight);
      return (Math.abs(font.descender) / font.unitsPerEm) * size;
    },
  };
}

  return buffer.buffer.slice(buffer.byteOffset, buffer.byteOffset + buffer.byteLength);
}

export function loadFontSet() {
  if (cached) return cached;
  const buffers = {};
  for (const [weight, file] of Object.entries(FONT_FILES)) buffers[weight] = toArrayBuffer(fs.readFileSync(path.join(FONT_DIR, file)));

(`opentype.js` has no `exports` map, so Node loads its CommonJS build and the default import is the module object with `parse`.

`diagram/shared/render/text.js` algorithm:
1. `const clean = String(text ?? '').normalize('NFC').replace(/\s+/g, ' ').trim()`; empty gives `{ lines: [], size, truncated: false }`.
2. `greedy(size)`: split `clean` on spaces; build lines word by word, starting a new line when `measure(line + ' ' + word) > maxWidth`; a word wider than `maxWidth` on its own is cut into chunks: take the longest prefix that fits (at least 1 character), repeat.
3. Try sizes from `size` down to `floor = Math.round(size * minScale * 2) / 2` in steps of 0.5: the first size whose `greedy` result has `<= maxLines` lines wins (`truncated: false`).
4. Otherwise use `floor`: keep the first `maxLines` lines; on the last kept line, append the rest of the text is dropped; then remove characters from its end (and trailing spaces) until `measure(line + '…') <= maxWidth`; set the line to `line + '…'`; `truncated: true`.

Note the test expects `size === 12` for a 16 px request: `16 * 0.75 = 12`.

`diagram/shared/render/color.js`: standard WCAG 2.x relative luminance (`c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4`, weights 0.2126 / 0.7152 / 0.0722) and ratio `(L1 + 0.05) / (L2 + 0.05)` with `L1` the lighter. `mixHex(fg, bg, amount)`: per channel `Math.round(fg * amount + bg * (1 - amount))`.

`diagram/shared/render/density.js` as in the interface.

import { wrapText } from './text.js';
import { roots, childrenOf } from '../spec/tree.js';

export const CANVAS_WIDTH = 960;
export const MARGIN = 40;
export const CONTENT_WIDTH = CANVAS_WIDTH - 2 * MARGIN;
export const TINT = 0.14;
export const TYPE = {
  title: { size: 28, weight: 700, lineHeight: 1.25 },
  subtitle: { size: 16, weight: 400, lineHeight: 1.4 },
  label: { size: 17, weight: 600, lineHeight: 1.3 },
  detail: { size: 13.5, weight: 400, lineHeight: 1.4 },
  small: { size: 12.5, weight: 500, lineHeight: 1.3 },
  value: { size: 22, weight: 700, lineHeight: 1.2 },
};
const LABEL_DETAIL_GAP = 4;

// One wrapped text item. Returns { item: null, height: 0 } for empty text.
export function textItem(ctx, text, { x, y, width, style, maxLines, anchor = 'start', fill = 'text', nodeId, role }) {
  const type = TYPE[style];
  const wrapped = wrapText(ctx.fontSet, text, { size: type.size, weight: type.weight, maxWidth: width, maxLines });
  if (wrapped.lines.length === 0) return { item: null, height: 0 };
  const lineHeight = wrapped.size * type.lineHeight;
  const height = wrapped.lines.length * lineHeight;
  const left = anchor === 'middle' ? x - width / 2 : anchor === 'end' ? x - width : x;
  return {
    item: { type: 'text', x, y, lines: wrapped.lines, size: wrapped.size, weight: type.weight, lineHeight, anchor, fill, box: { x: left, y, w: width, h: height }, nodeId, role },
    height,
  };
}

// Label + detail of a node stacked from y. onFill: the text sits on a solid accent.
export function nodeText(ctx, node, { x, y, width, anchor = 'start', labelLines = 2, detailLines = 3, onFill = false, labelStyle = 'label' }) {
  const label = textItem(ctx, node.label, { x, y, width, style: labelStyle, maxLines: labelLines, anchor, fill: onFill ? 'onAccent' : 'text', nodeId: node.id, role: 'node-label' });
  const detailY = y + label.height + (label.height > 0 ? LABEL_DETAIL_GAP : 0);
  const detail = detailLines > 0
    ? textItem(ctx, node.detail, { x, y: detailY, width, style: 'detail', maxLines: detailLines, anchor, fill: onFill ? 'onAccent' : 'mutedText', nodeId: node.id, role: 'node-detail' })
    : { item: null, height: 0 };
  const items = [label.item, detail.item].filter(Boolean);
  const height = detail.height > 0 ? detailY - y + detail.height : label.height;
  return { items, height };
}

// Centred title and subtitle. bottom already includes the gap before the diagram.
export function titleBlock(spec, ctx, { y = MARGIN, width = CANVAS_WIDTH } = {}) {
  const textWidth = Math.min(width - 2 * MARGIN, 760);
  const title = textItem(ctx, spec.title, { x: width / 2, y, width: textWidth, style: 'title', maxLines: 2, anchor: 'middle', role: 'title' });
  const subY = y + title.height + (title.height > 0 ? 8 : 0);
  const subtitle = textItem(ctx, spec.subtitle, { x: width / 2, y: subY, width: textWidth, style: 'subtitle', maxLines: 2, anchor: 'middle', fill: 'mutedText', role: 'subtitle' });
  const used = subtitle.height > 0 ? subY - y + subtitle.height : title.height;
  return { items: [title.item, subtitle.item].filter(Boolean), bottom: used > 0 ? y + used + ctx.density.gap * 1.2 : y };
}

export function slotFor(index) {
  return `accent${(index % 6) + 1}`;
}

// Colour slot of a node in hierarchical templates: an explicit colour on the node or an
// ancestor wins; otherwise each branch under a single root gets its own slot.
export function accentFor(spec, nodeId) {
  const byId = new Map(spec.nodes.map((n) => [n.id, n]));
  const chain = [];
  for (let node = byId.get(nodeId); node; node = node.parent ? byId.get(node.parent) : null) {
    if (node.color) return node.color;
    chain.push(node);
  }
  const top = chain[chain.length - 1];
  const rootList = roots(spec);
  if (rootList.length === 1 && chain.length >= 2) {
    const branch = chain[chain.length - 2];
    return slotFor(childrenOf(spec, top.id).findIndex((n) => n.id === branch.id));
  }
  return slotFor(Math.max(0, rootList.findIndex((n) => n.id === top.id)));
}

// Emphasised nodes are solid accent boxes, the rest are light tints.
export function boxFill(node, accent) {
  return node.emphasis ? accent : { token: accent, mix: TINT };
}

// Round icon badge: a solid circle with the icon on top. For a node drawn on a solid
// accent box (emphasis) call it as badge(node, 'onAccent', { ..., iconColor: accent }).
export function badge(node, fill, { cx, cy, r, iconColor = 'onAccent' }) {
  const size = r * 1.1;
  return [
    { type: 'circle', cx, cy, r, fill, stroke: 'none', nodeId: node.id, role: 'node-icon' },
    { type: 'icon', name: node.icon, x: cx - size / 2, y: cy - size / 2, size, color: iconColor, nodeId: node.id, role: 'node-icon' },
  ];
}

export function pathItem(d, points, { fill = 'none', stroke = 'stroke', strokeWidth = 2, dash = false, nodeId, role = 'connector' } = {}) {
  const xs = points.map((p) => p.x);
  const ys = points.map((p) => p.y);
  const x = Math.min(...xs);
  const y = Math.min(...ys);
  return { type: 'path', d, fill, stroke, strokeWidth, dash, bounds: { x, y, w: Math.max(...xs) - x, h: Math.max(...ys) - y }, nodeId, role };
}

// Filled triangle with its tip at (x, y) pointing along angle (radians).
export function arrowHead(x, y, angle, { size = 10, paint = 'stroke' } = {}) {
  const spread = (150 * Math.PI) / 180;
  const a = { x: x + size * Math.cos(angle + spread), y: y + size * Math.sin(angle + spread) };
  const b = { x: x + size * Math.cos(angle - spread), y: y + size * Math.sin(angle - spread) };
  const d = `M${x.toFixed(2)} ${y.toFixed(2)}L${a.x.toFixed(2)} ${a.y.toFixed(2)}L${b.x.toFixed(2)} ${b.y.toFixed(2)}Z`;
  return pathItem(d, [{ x, y }, a, b], { fill: paint, stroke: 'none', strokeWidth: 0, role: 'connector' });
}

export function unionBox(boxes) {
  const x = Math.min(...boxes.map((b) => b.x));
  const y = Math.min(...boxes.map((b) => b.y));
  const right = Math.max(...boxes.map((b) => b.x + b.w));
  const bottom = Math.max(...boxes.map((b) => b.y + b.h));
  return { x, y, w: right - x, h: bottom - y };
}

export function finishScene({ width = CANVAS_WIDTH, items, nodes, bottom }) {
  return { width: Math.ceil(width), height: Math.ceil(bottom + MARGIN), items, nodes };
}

function columnsFor(count) {
  if (count <= 3) return count;
  return count === 4 ? 2 : 3;
}

export default {
  id: 'cards',
  kind: 'list',
  label: 'Thẻ',

  maxNodes: 9,

    const head = titleBlock(spec, ctx);
    const items = [...head.items];
    const nodes = {};

    const columns = Math.max(1, columnsFor(count));
    const cardWidth = (CONTENT_WIDTH - gap * (columns - 1)) / columns;
    const textWidth = cardWidth - 2 * pad;
    let y = head.bottom;
    for (let start = 0; start < count; start += columns) {
      const row = spec.nodes.slice(start, start + columns);
      const texts = row.map((node) => {

        nodes[node.id] = { x, y, w: cardWidth, h: rowHeight };
      });
      y += rowHeight + gap;
    }
    return finishScene({ width: CANVAS_WIDTH, items, nodes, bottom: y - gap });

import assert from 'node:assert/strict';

const EPS = 0.5;

export function itemBounds(item) {
  switch (item.type) {
    case 'rect': return { x: item.x, y: item.y, w: item.w, h: item.h };
    case 'circle': return { x: item.cx - item.r, y: item.cy - item.r, w: item.r * 2, h: item.r * 2 };
    case 'path': return item.bounds;
    case 'text': return item.box;
    case 'icon': return { x: item.x, y: item.y, w: item.size, h: item.size };
    default: throw new Error(`unknown item type ${item.type}`);
  }
}

function overlaps(a, b) {
  return a.x < b.x + b.w - EPS && b.x < a.x + a.w - EPS && a.y < b.y + b.h - EPS && b.y < a.y + a.h - EPS;
}

export function assertSceneInvariants(scene, spec, fontSet, { allowNodeOverlap = false } = {}) {
  assert.ok(Number.isFinite(scene.width) && scene.width > 0, 'width');
  assert.ok(Number.isFinite(scene.height) && scene.height > 0, 'height');
  for (const item of scene.items) {
    const b = itemBounds(item);
    for (const v of [b.x, b.y, b.w, b.h]) assert.ok(Number.isFinite(v), `${item.type} ${item.role} has a non-finite bound`);
    assert.ok(b.x >= -EPS && b.y >= -EPS && b.x + b.w <= scene.width + EPS && b.y + b.h <= scene.height + EPS,
      `${item.type} ${item.role} ${item.nodeId ?? ''} is outside the canvas: ${JSON.stringify(b)} in ${scene.width}x${scene.height}`);
    if (item.type === 'text') {
      for (const line of item.lines) {
        assert.ok(fontSet.measure(line, item.size, item.weight) <= item.box.w + EPS, `line "${line}" overflows its box`);
      }
      assert.ok(item.lines.length * item.lineHeight <= item.box.h + EPS, 'text taller than its box');
    }
  }
  for (const node of spec.nodes) assert.ok(scene.nodes[node.id], `node ${node.id} has no hit box`);
  if (!allowNodeOverlap) {
    const boxes = Object.entries(scene.nodes);
    for (let i = 0; i < boxes.length; i += 1) {
      for (let j = i + 1; j < boxes.length; j += 1) {
        assert.ok(!overlaps(boxes[i][1], boxes[j][1]), `nodes ${boxes[i][0]} and ${boxes[j][0]} overlap`);
      }
    }
  }
}

4. Even indices go above the axis, odd below.
   `aboveH` = tallest card above, `belowH` = tallest card below.

   An above card's bottom sits at `axisY - 36`; a below card's top at `axisY + 36`.
5. Axis: `rect` from `MARGIN` to `MARGIN + CONTENT_WIDTH`, height 4, centred on `axisY`, `radius: 'pill'`, fill `'stroke'`, `role: 'decoration'`.
6. Per node: connector `path` (vertical line from the axis to the card edge, `stroke: accent`, width 2), dot `circle` at `(cx_i, axisY)` radius 9 fill accent with stroke `'background'` width 3, the card `rect` (`radius: 'theme'`, `boxFill`, `shadow: true`), the icon and the texts.

4. Arrows between consecutive nodes (`i -> i + 1`, and last -> first): an arc on the circle of radius `R` from `theta_i + delta` to `theta_(i+1) - delta`, where `delta = Math.asin(Math.min(1, (Math.hypot(boxW, boxH) / 2 + 8) / R))`; skip the arc when `2 * delta >= 2 * PI / n`.
   Path `M x0 y0 A R R 0 0 1 x1 y1`, `stroke: 'stroke'`, width 2.5; `bounds` = the full circle `{ x: cx - R, y: cy - R, w: 2R, h: 2R }`; arrow head at `(x1, y1)` with angle `theta_end + PI / 2`.
5. In the centre, when `R > 120`, a `circle` of radius `Math.min(R - boxH / 2 - 20, 70)` with tint fill of `accent1` and an icon `refresh-cw` in `accent1` (role `decoration`).
6. Hit box = each node rect; `bottom = cy + R + boxH / 2`.

**`tree` layout (top-down, tidy):**
1. Roots = `roots(spec)`; several roots are laid out side by side as a forest.
2. Box width `boxW = 160`; measure every node box height; level `d` height = max box height at depth `d`; level `d` top `y_d = head.bottom + sum(level heights before d) + d * gap * 1.6`.
3. Subtree width `sw(node) = max(boxW, sum(sw(children)) + gap * (children - 1))`; place recursively: a node's children are laid out left to right inside its subtree span, and the node is centred above its children's span (or its own span for a leaf).
   Forest: roots side by side with `gap * 1.5` between them.
4. `contentW = total forest width`; width rule as above; centre the forest horizontally.
5. Connectors: for each child, an elbow `path` from parent bottom-centre `(px, pb)` to `(px, mid)` to `(cx, mid)` to child top-centre `(cx, ct)` with `mid = pb + (ct - pb) / 2`, using rounded corners is optional; `stroke: 'stroke'`, width 2.
6. Roots are drawn solid (fill = accent) with `onAccent` text whether or not emphasised; other nodes use `boxFill`.
7. Hit box = each node rect.

**`mindmap` layout (left / right):**
1. Centre node: the single root when `roots(spec).length === 1`; otherwise a synthetic centre that shows `spec.title` (or `'…'` when empty) as a `decoration` pill (it has no `nodeId`), and every root becomes a branch.
2. Branches = children of the centre.
   The first `Math.ceil(k / 2)` branches go right, the rest left.
3. Sizes: centre width 170 (pill rect, `radius: 'pill'`, solid accent1, `onAccent` label, no detail), branch width 150, leaf width 150.
   Every node below a branch (any depth) is a leaf, listed under the branch in depth-first order, indented by `12 * (depth - 2)` px for depth > 2 (the leaf box gets narrower by the indent).
4. Column x positions on the right side: centre box right edge + 48 = branch column left; branch column right + 40 = leaf column left.
   Mirror for the left side.
   Content width = `150 + 40 + 150 + 48 + 170 + 48 + 150 + 40 + 150 = 946`, so the canvas is 1026 wide (width rule).
   When a side has no leaves at all, its leaf column is not reserved (shrink the width accordingly; keep the centre centred on the canvas).
5. Each side stacks its branches top to bottom; a branch block height is `max(branch box height, sum(leaf heights) + gap / 2 * (leaves - 1))`; blocks are separated by `gap`.
   The branch box is vertically centred on its block; leaves are stacked from the block top.
   The taller side defines the content height; the shorter side is vertically centred against it; the centre box is vertically centred on the content.
6. Connectors: cubic Bezier `path` from the centre box edge (right or left middle) to the branch box's facing edge middle, and from the branch box's outer edge middle to each leaf's facing edge middle: `M x0 y0 C (x0 + dx/2) y0, (x1 - dx/2) y1, x1 y1`; `stroke` = the branch accent, width 2.5 (centre to branch) and 1.5 (branch to leaf).
   `bounds` from the four control points.
7. Branch boxes: solid accent with `onAccent` text when emphasised, tint otherwise; leaves: `rect` with fill `'background'`, stroke accent 1.5, label `labelLines: 2`, detail `detailLines: 2`.
8. Hit boxes: every real node (centre root included when it is a real node); the synthetic centre has none.

**Ingest rules** (block ids are `b0`, `b1`, ... in document order; all text NFC-normalised; blocks with empty text are skipped):

- `ingestText(text)` (typed text and `.txt`): strip a leading BOM, normalise `\r\n` to `\n`, split on blank lines (`/\n\s*\n/`).
  A chunk whose every line matches `/^\s*([-*•]|\d+[.)])\s+/` is a `list` block (text = the lines, trimmed, joined with `\n`).
  A one-line chunk matching `/^#{1,6}\s+/` is a `heading` with `level` = number of `#` (text without the hashes).
  Anything else is a `paragraph` (lines joined with `\n`).
  `format` is `'text'` (the caller sets `'txt'` for files); `title` = the first heading's text, else the first 60 characters of the first block.
- `.md` / `.markdown`: `marked.lexer(text)`; `heading` -> heading (`depth` as level, `text`), `paragraph` -> paragraph (`text`), `list` -> list (items' `text` joined as `- item` lines), `code` -> paragraph, `blockquote` -> paragraph (`text`), `table` -> table (header and rows' cell `text` joined with ` | ` per row, rows by `\n`); `space`, `hr`, `html` are skipped.
- `.docx`: open with JSZip; read `word/document.xml`; for each element child `i` of `w:body` (via `childElements`):
  - `w:p`: text = all `w:t` text in order, `w:tab` as a space, `w:br` as `\n`; heading level from `w:pPr/w:pStyle/@w:val` matching `/^heading\s?([1-6])$/i` (level N) or `/^title$/i` (level 1), else from `w:pPr/w:outlineLvl/@w:val` (level = val + 1, only 0-5); a paragraph with `w:pPr/w:numPr` is a list item.
    Consecutive list items merge into one `list` block whose text is `- item` lines and whose `source.bodyIndex` is the index of its last item.
  - `w:tbl`: one `table` block, rows (`w:tr`) as lines, cells (`w:tc`) joined with ` | `.
  - anything else (`w:sectPr`, `w:sdt`, bookmarks): skipped.
  - `source = { bodyIndex: i }`; `title` = `docProps/core.xml` `dc:title` when non-empty, else the first heading, else the first 60 characters.
- `.pptx`: read `ppt/presentation.xml` `p:sldIdLst/p:sldId` in order, resolve each `r:id` through `ppt/_rels/presentation.xml.rels` to a part (`slides/slide3.xml` -> `ppt/slides/slide3.xml`).
  For each slide: every `p:sp` shape, its `a:p` paragraphs' `a:t` text; the slide title is the text of the shape whose `p:nvSpPr/p:nvPr/p:ph/@type` is `title` or `ctrTitle`, else the first non-empty paragraph.
  Block text = title, then the other paragraphs, joined with `\n`; `kind: 'slide'`; `source = { slidePart, slideIndex }`.
  `title` = `docProps/core.xml` title, else the first slide's title.
- Any other extension: `AppError('bad_input', 'Chỉ hỗ trợ .txt, .md, .docx, .pptx.')`.
  A `.docx` / `.pptx` that is not a zip (does not start with `PK`) or misses its main part: `AppError('bad_input', 'Không đọc được tệp Office này.')`.
  A document with no blocks at all: `AppError('bad_input', 'Không tìm thấy nội dung chữ trong tệp.')`.

### Task 10: URL ingest with an SSRF guard

**Files:**
- Create: `diagram/server/ingest/url-guard.js`, `diagram/server/ingest/url.js`
- Modify: `diagram/server/ingest/index.js` (export `ingestUrl`)
- Test: `diagram/test/ingest-url.test.js`

**Interfaces:**
- Produces:
  - `isBlockedAddress(ip: string) -> boolean`.
  - `guardedFetch(url, { fetchImpl = fetch, lookup = dns.promises.lookup, maxBytes = 5 * 1024 * 1024, timeoutMs = 15000, maxRedirects = 3 }) -> Promise<{ url: finalUrl, contentType, body: string }>`.
  - `ingestUrl(url, deps = {}) -> Promise<Document>` (`format: 'url'`, `url: finalUrl`); `deps` is passed through to `guardedFetch`.

Rules:
- `isBlockedAddress` uses a `net.BlockList` with: IPv4 `0.0.0.0/8`, `10.0.0.0/8`, `100.64.0.0/10`, `127.0.0.0/8`, `169.254.0.0/16`, `172.16.0.0/12`, `192.0.0.0/24`, `192.168.0.0/16`, `198.18.0.0/15`, `224.0.0.0/3`; IPv6 `::/128`, `::1/128`, `fc00::/7`, `fe80::/10`, `ff00::/8`; an IPv4-mapped IPv6 address (`::ffff:a.b.c.d`) is checked as its IPv4 address.
- `guardedFetch` loop (at most `maxRedirects + 1` requests):
  1. `new URL(url)`; protocol must be `http:` or `https:`; no username or password; otherwise `AppError('url_blocked')`.
  2. Hostname that is an IP literal is checked directly; otherwise `lookup(hostname, { all: true, order: 'ipv4first' })`; if the list is empty or **any** address is blocked: `AppError('url_blocked', 'Địa chỉ này trỏ vào mạng nội bộ.')`.
  3. `fetchImpl(url, { redirect: 'manual', signal: AbortSignal.timeout(timeoutMs), headers: { 'user-agent': 'DiagramStudio/0.1', accept: 'text/html,text/plain;q=0.9' } })`.
  4. Status 301/302/303/307/308 with a `location` header: resolve it against the current URL and loop; more than `maxRedirects` redirects: `AppError('url_failed', 'Trang chuyển hướng quá nhiều lần.')`.
  5. Non-2xx: `AppError('url_failed', 'Trang web trả về lỗi ' + status + '.')`.
  6. `content-type` must start with `text/html` or `text/plain`, else `AppError('url_failed', 'Địa chỉ này không phải trang web có chữ.')`.
  7. Read `response.body` as a stream, counting bytes; over `maxBytes`: cancel the reader and throw `AppError('url_failed', 'Trang web quá lớn.')`.
     Decode with `new TextDecoder(charset)` where `charset` comes from the content type (default `utf-8`; an unknown charset falls back to `utf-8`).
  8. A timeout (`TimeoutError`) or network error: `AppError('url_failed', ...)` with the cause as `detail`.
- `ingestUrl`: `text/plain` goes through `ingestText`; HTML: `parseHTML(body)` from `linkedom`, `new Readability(document).parse()`; when it returns an article, parse `article.content` again with `linkedom` and walk it in document order: `h1`-`h6` -> heading, `p` -> paragraph, each `ul` / `ol` -> one list block (`- item` lines), `pre` / `blockquote` -> paragraph, `table` -> table (rows of cells joined with ` | `); nested elements inside an already-taken block are not visited again.
  When Readability returns null, fall back to the same walk over `document.body`.
  `title` = `article.title` or `<title>`; `source: null` on every block.
- `server/main.js` (Task 12) calls `dns.setDefaultResultOrder('ipv4first')`; IPv6 is broken on the user's network.

Note: the address check and the connection use separate DNS lookups, so a hostile DNS server could still race them (DNS rebinding).
That is acceptable for a single-user tool behind a token; write that sentence as a comment above `guardedFetch`.

**Retry:** `createAgent().run` calls the adapter, validates with Ajv (`allErrors: true`), runs `postprocess`; on an Ajv error or `BadOutput` it calls the adapter once more with the user message plus `\n\nYour previous answer was rejected: <reasons>. Return a corrected JSON object.`; a second failure becomes `AppError('agent_bad_output', undefined, { detail: first 2000 chars of the raw output })`.
Every call gets `signal: AbortSignal.any([callerSignal, AbortSignal.timeout(config.agentTimeoutMs)])`; when the timeout fires the error is `agent_timeout`, when the caller aborts it is `cancelled`.

**Segment shortcut:** `shouldSkipSegment(document)` is true when the document has at most 4 blocks and at most 1,500 characters of text; the routes then create `singleSection(document)` = `{ id: 's1', blockIds: all, title: document.title, summary: '', suggestedKinds: [] }` without calling the agent.

  const calls = [];

    const child = new EventEmitter();
    child.stdin = new PassThrough();
    child.stdout = new PassThrough();
    child.stderr = new PassThrough();

Rules:
- Auth: an `onRequest` hook on every `/api/` route except `/api/health`: when `config.token` is set, require `authorization: Bearer <token>`; compare with `crypto.timingSafeEqual` on equal-length buffers (different lengths fail without comparing).
  Failure: 401 `unauthorized`.
  Static files are served without auth (they contain no data).
- Every agent route: `locks.acquire(id)` (409 `busy` when one is running), run with `signal: controller.signal`, `locks.release` in `finally`.
  Answers sent with the request are merged into `project.answers` before the call, and `pendingQuestions` is cleared.
  When the agent returns questions, set `pendingQuestions = { task, sectionId, questions }` and save.
- Unknown section id: 404 `not_found`.
- Error handler: `AppError` -> its status and envelope; Fastify validation and body-size errors -> 400 `bad_input`; anything else -> 500 `internal` with the error logged.
  Log `AppError.detail` at `warn`, never send it to the client.
- Multipart: `@fastify/multipart` with `limits: { fileSize: 20 * 1024 * 1024, files: 1 }`; a truncated file (`file.truncated`) is `bad_input` `'Tệp lớn hơn 20 MB.'`.

  `<hash>` is the base64 SHA-256 of the exact text inside the inline `<script type="importmap">` of `web/index.html` (Task 15); browsers do not load import maps from a `src`, so the inline map is allowed by its hash and no other inline script runs.
